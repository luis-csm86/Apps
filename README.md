# APP LAUNCHPAD

**To add an app later:**
- Edit the *APPS* list at the top of the script.
- Copy one block and change the *name*, *URL*, *description*, *host*, and *color*.
- For the *icon*, use one of chart, calendar, book, steps, music, or link as a generic fallback.
- The *tags* field holds extra words the search will match, like "spotify" for Music Rankings.
